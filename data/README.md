# Data
`creditcard.csv` is the public credit card fraud dataset from the ULB Machine Learning Group and Worldline:
284,807 card transactions made by European cardholders over two days in September 2013, 492 labeled fraud.
Columns: Time (seconds since the first transaction), V1-V28 (PCA-transformed features, anonymized), Amount, Class (1 = fraud).

Get it from the original source: Kaggle, "Credit Card Fraud Detection" by ULB Machine Learning Group. Place the file here as `data/creditcard.csv`.
The copy used to build this project had SHA-256 `33a178be65174943a07d1736acf5898f6c8e1fa80950dbbe598c17eda968ec59`
(102,634,230 bytes). If yours differs, your numbers will differ slightly.

Citation: Dal Pozzolo, A., Caelen, O., Johnson, R. and Bontempi, G. "Calibrating Probability with Undersampling for Unbalanced Classification." IEEE CIDM, 2015.
Check the dataset's license terms on Kaggle before republishing the raw file; do not commit it to GitHub (it is 100 MB).
